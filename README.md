## how to play
- control the snake to collect pumpkins to inc size 
-avoid collisions

## Controls 
- Arrow keys - Move the snake 
- esc - quiet the game
- R - to replay

## run locally
**requirements**
Python 3.10 or newer
pip
git

1- Clone the repo
```
git clone https://github.com/nAItiklearn/snake-game.git
cd snake-game
```
2- create a virtual environment(recommended)
-- WINDOWS 
```
python -m venv .venv
.venv\Scripts\Activate.ps1
```
-- MAC/LINUX
```
python3 -m venv .venv
source .venv/bin/activate
```
3- Install pygame 
```
python -m pip install pygame
```
4- run it!
```
python main.py
```
